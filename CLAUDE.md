# astro-channel

Автопостинг ежедневной «астропогоды» в Telegram-канал.

- Ежедневная задача целиком описана в `INSTRUCTIONS.md`.
- Факты о небе берутся только из `scripts/sky.py` (NASA JPL Horizons).
- Значения переменных окружения `TELEGRAM_*` никогда не выводить в логи и ответы.
- Папка `out/` временная, её не коммитить.
